# Emotion Detection Application

## Project Overview
This project implements an Emotion Detection application using IBM Watson Natural Language Processing (NLP).

## Objective
The application analyzes input text and identifies emotions expressed in the text, including anger, disgust, fear, joy, and sadness.

## Technologies Used
- Python
- IBM Watson NLP Emotion Detection API
- Flask
- Unit Testing
- Pylint for static code analysis

## Project Features
- Emotion detection from text input
- Formatted emotion analysis results
- Unit testing and error handling
- Flask-based web deployment
- Static code quality analysis
